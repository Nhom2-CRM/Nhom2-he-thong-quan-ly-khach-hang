# S1-05 Frontend
React + TypeScript. Giao diện cho 4 nhóm dữ liệu: khách hàng, cơ hội, hoạt động, báo giá.

Backend chịu trách nhiệm áp dụng phạm vi MINE / TEAM / ALL cho danh sách, tìm kiếm, chi tiết và xuất Excel.

## Chạy
- `npm install`
- `npm run dev`

Mặc định gọi backend tại `http://127.0.0.1:8000`.
